# 실내 장착 미리보기 — POC 뷰어 v0.2

차량 실내 샘플 3D에 카테고리별 상품을 골라 장착 결과를 미리 보는 웹 시뮬레이터.
오늘의집 3D 방꾸미기를 참고한 소비자용 UX로, 계획서 4.3절 뷰어의 제품화 방향 구현이다.
유료 에셋·서비스를 쓰지 않는다 (three.js 0.180.0, MIT, CDN — 빌드·호스팅 비용 없음).

## v0.2 설계 원칙 (v0.1과의 차이)

| | v0.1 (엔지니어용) | v0.2 (소비자용) |
|---|---|---|
| 베이스 | 사용자가 GLB/스플랫 업로드 | 샘플 실내 내장 — 열면 바로 사용 |
| 배치 | 표면 탭 + 이동·회전·크기 기즈모 | 상품 선택 → 정해진 장착 위치에 자동 장착 |
| 카메라 | 수동 조작 | 장착 시 해당 부위로 자동 이동(장착 구도) |
| 옵션 | 축 보정·스케일·색온도 등 전문가 패널 | 색상 스와치·제거·시점·내장색만 노출 |
| 저장 | JSON 복사/붙여넣기 | 브라우저 자동 저장(localStorage) + 스크린샷 |

v0.1의 업로드·축 보정·실측 스케일 기능은 git 이력(커밋 `75256e6`)에 보존되어 있다.
3DGS 스플랫 실사 베이스 검증 단계에서 내부 도구로 다시 쓴다.

## 화면 구성

- **상단**: 시점 칩(전체/운전석/조수석/2열), 내장색 토글(블랙/화이트 — MVP 내장색 2종 범위)
- **하단 드로어**: 카테고리 칩(트림·데코/조명/콘솔/거치대/매트) + 상품 카드(절차 생성 썸네일, 예시 가격)
- **카드 탭** → 즉시 장착 + 카메라 이동 + 옵션 시트(색상 스와치, 제거)
- **3D에서 장착된 상품 탭** → 같은 옵션 시트
- **우하단**: 스크린샷, 장착 목록(합계·개별 제거·전체 비우기)

## 상품 카탈로그 (10종, 전부 절차 생성 3D + 고정 장착 좌표)

| 카테고리 | 상품 | 옵션 |
|---|---|---|
| 트림·데코 | 대시보드 트림 / 도어 트림 2P / 스티어링 휠 커버 | 카본·우드·화이트 |
| 조명 | 엠비언트 라이트 세트 / 풋웰 라이트 | 아이스블루·웜화이트·퍼플·레드 |
| 콘솔 | 컵홀더 트레이 / 콘솔 오거나이저 | 블랙·카본 / 블랙·화이트 |
| 거치대 | 폰 거치대 | 좌측·우측 장착 위치 |
| 매트 | 1열 매트 세트 / 2열 매트 | 블랙·베이지 |

상품·가격은 예시 데이터다. MVP에서 실제 판매 상품(제휴 링크)·호환 데이터로 교체한다.

## 기술 메모

- 샘플 실내는 모델Y 스타일 절차 생성 플레이스홀더(실차 아님). 센터 디스플레이만 실측(15.4", 340×194mm).
- 상품 썸네일은 앱 시작 시 각 상품을 오프스크린 미니 렌더러로 찍어 생성 — 이미지 에셋 0개.
- 장착 위치는 상품별 고정 좌표(슬롯 방식). 차종·연식·트림 호환 데이터 구조(계획서 5.4)로 확장하는 입구가 된다.
- MVP에서 베이스를 자체 촬영 3DGS로 교체 시, 슬롯 좌표만 실측 기준으로 다시 잡으면 상품·UI는 그대로 재사용.
- FPS 표시는 우하단(통과 기준: 중급 스마트폰 30fps).
