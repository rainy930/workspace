# 실내 장착 미리보기 — POC 뷰어 v0.1

차량 실내 3D 장면에 상품 3D 모델을 배치해 장착 결과를 미리 보는 웹 뷰어.
계획서 4.3절(뷰어 기능 POC 범위)의 무료 구현이다. 유료 에셋·서비스를 쓰지 않는다.

## 구성 (전부 무료)

| 항목 | 선택 | 비고 |
|---|---|---|
| 렌더링 | three.js 0.180.0 (MIT, CDN) | 환경광은 RoomEnvironment(절차 생성) |
| 스플랫 렌더링 | Spark `@sparkjsdev/spark` 2.3.1 (MIT, CDN) | .spz / .ply / .splat / .ksplat |
| 베이스 | ① 절차 생성 플레이스홀더 실내 ② 로컬 GLB 업로드 ③ 로컬 스플랫 업로드 | 구매 3D 모델($149~) 대체 |
| 상품 3~5개 | 절차 생성: 판형 트림, 엠비언트 라인, 컵홀더 트레이, 폰 거치대, 매트 | 형상 유형 분산(계획서 5.2) |
| 호스팅 | 단일 `index.html` — 아무 정적 호스팅/아티팩트에서 동작 | 빌드 불필요 |

플레이스홀더 실내는 실차가 아니며 UI·배치·재질·조명 파이프라인 검증용이다.
실사감 검증(통과 기준 5.3)은 GLB/스플랫 베이스를 넣어서 진행한다.
센터 디스플레이만 실측(15.4", 대각 391mm ≈ 340×194mm)으로 만들어 스케일 보정 기준점으로 쓸 수 있다.

## 구현된 기능 (계획서 4.3 대비)

- [x] 베이스 불러오기: GLB(GLTFLoader.parse, 로컬 파일), 스플랫(Spark SplatMesh fileBytes)
- [x] 축 보정: X/Y/Z ±90°, 상하 반전, 높이 이동, 로그 스케일 조절, 초기화
- [x] 실측 스케일 보정: 두 점 탭 측정 → 실제 길이(mm) 입력 → 배율 적용 (프리셋 391mm / 203mm)
- [x] 상품 배치: 탭 지점 표면 스냅(법선 정렬), TransformControls 이동·회전·크기, 복제·삭제
  - 스플랫 베이스: 면 법선이 없으므로 인접 3점 레이캐스트로 법선 추정 (계획서 명세)
- [x] 재질 교체: 카본 / 우드 / 화이트 글로스 / 스웨이드 / 블랙 매트 (전부 캔버스 절차 텍스처)
  - 엠비언트 라인: 발광색·세기 조절
- [x] 조명 맞춤: 환경광 세기, 주광 세기·방위·고도, 색온도(2200–10000K), 접지 그림자 토글·바닥 높이
- [x] 시점 프리셋: 운전석 / 조수석 / 2열 / 콘솔 상단 / 전체
- [x] 저장: 배치 JSON 복사·붙여넣기 복원, 스크린샷(이미지 표시 후 길게 눌러 저장)
- [x] FPS 표시 (통과 기준: 중급 스마트폰 30fps)

## 사용 순서

1. `index.html`을 브라우저에서 연다 (또는 게시된 아티팩트 링크).
2. 기본 실내에서 상품 탭 → 상품 선택 → 표면 탭으로 배치 흐름을 확인한다.
3. 실제 베이스 검증: GLB 또는 3DGS 스플랫 파일을 불러온다.
   - 뒤집혀 보이면 "상하 반전", 이후 높이·회전 보정.
   - 센터 디스플레이 대각선 두 점을 측정하고 391mm를 적용해 실측 스케일을 맞춘다.
4. 조명 탭에서 촬영 당시 조명과 비슷하게 맞춘 뒤 스크린샷으로 실사감 평가(5.3)에 쓴다.

## 알려진 제약

- DRACO/KTX2 압축 GLB는 지원하지 않는다(디코더 외부 파일 필요). 비압축 GLB로 내보낼 것.
- 스플랫 레이캐스트는 근사이므로 배치 후 기즈모로 미세 조정이 필요할 수 있다.
- 베이스 파일 자체는 JSON에 저장되지 않는다. 복원 전 같은 베이스를 다시 불러와야 한다.
- 3DGS 학습(촬영 경로)은 별도 GPU 머신이 필요하다 — 계획서 4.5절.
