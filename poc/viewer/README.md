# 실내 장착 미리보기 — POC 뷰어 v0.3

테슬라 호환 차종을 고르고, 외관(도장 색상·외장 용품)과 내관(실내 용품)을 조합해 보는 웹 시뮬레이터.
오늘의집 3D 방꾸미기식 소비자 UX. 유료 에셋·서비스 없음 (three.js 0.180.0 MIT, CDN, 빌드 불필요).

## 흐름

1. **차량 선택**: 모델 Y 주니퍼(2025~) / 모델 Y 레거시(2020~24) / 모델 3 하이랜드(2024~)
   - 차량명은 호환 대상 표기(제조사 무관 고지), 차체·실내는 절차 생성 근사 모델
2. **외관 모드**: 도장 색상 6종(스텔스 그레이 등), 외장 용품 장착, 시점(전체/전면/후면/측면)
3. **내관 모드**: 카테고리별 실내 용품 장착, 내장색(블랙/화이트), 시점(전체/운전석/조수석/2열)
4. 상품 탭 → 고정 장착 위치에 자동 장착 + 카메라가 장착 부위로 이동 → 색상 스와치로 옵션 변경
5. 장착 목록(합계, 텍스트 복사 — 커뮤니티 공유용), 스크린샷, 차량별 브라우저 자동 저장

## 호환 데이터 (계획서 핵심 차별점의 데모)

리서치 근거를 반영한 차종별 `fit` 필터 — 선택한 차에 맞는 상품만 노출:

- **주니퍼는 센터 콘솔·대시 플랫폼을 모델 3 하이랜드와 공유** → 콘솔류(컵홀더 트레이, 오거나이저, 도어 포켓 수납함)는 주니퍼·하이랜드 호환, 레거시 미노출
- **후석 디스플레이 필름**: 후석 8" 디스플레이가 있는 주니퍼·하이랜드만 (레거시 실내에는 후석 디스플레이 자체가 없음 — 실내 모델도 차종별로 분기)
- **글라스루프 선쉐이드**: 모델 Y 계열만
- 옵션 시트에 "호환: …" 표기

레거시(2020~24) 용품의 주니퍼 호환율이 ~35%라는 업계 자료(Basenor)가 이 구조의 근거.

## 카탈로그 (20종, 전부 절차 생성 3D)

- 실내 16종: 트림·데코(대시보드 트림, 도어 트림, 스티어링 커버) / 조명(엠비언트 확장, 풋웰) /
  콘솔·수납(컵홀더 트레이, 오거나이저, 도어 포켓 수납함, 폰 거치대) /
  매트·보호(TPE 올웨더 1열·2열, 시트백 킥매트, 도어씰 프로텍터) /
  필름·차양(센터·후석 디스플레이 필름, 글라스루프 선쉐이드)
- 외장 4종: 리어 스포일러, 머드 플랩, 도어 핸들 커버, 에어로 휠 캡
- `인기` 태그: 직구·커뮤니티에서 자주 언급되는 품목(올웨더 매트, 오거나이저, 도어 포켓, 선쉐이드, 머드 플랩, 디스플레이 필름) 기반 데모

리서치 출처: Basenor 주니퍼 가이드/호환 문서, EVAAM 주니퍼-레거시 호환 가이드, teslaunch 주니퍼 카탈로그, 오너 포럼(teskas).

## 기술 메모

- 외관: 측면 프로파일 Shape → ExtrudeGeometry(베벨) 차체 + 글라스 캐노피, 바퀴·라이트·미러 절차 생성.
  차체는 벨트라인까지, 상부는 글라스 캐노피가 덮는 구조(베벨 확장으로 글라스가 묻히는 문제 회피)
- 내관: v0.2 샘플 실내 + 차종별 분기(후석 디스플레이 유무)
- 썸네일: 상품 20종 + 차량 3종을 시작 시 오프스크린 미니 렌더로 생성 — 이미지 에셋 0개
- 저장: `localStorage`에 차량별(테마·도장·장착 목록) 저장, 접근 불가 환경은 무시
- 외관/내관 전환: 내관에서 차체 숨김, 외장 상품도 함께 숨김. 실내 상품은 외관에서 유리 너머로 보임
- MVP에서 베이스를 실측 3DGS로 교체 시 장착 슬롯 좌표만 재측정하면 카탈로그·UI 재사용

- **외관**: 실차 팬메이드 GLB를 CDN 없이 동봉 로드
  - 모델 Y (주니퍼·레거시): "2021 Tesla Model Y" © tonielpro520, **CC-BY 4.0** + TMC 개조판(도어/휠 분절) — 상업 사용 가능(출처 표기)
  - 모델 3 (하이랜드): "Tesla Model 3" © OneSteven, **CC-BY-NC 4.0** — POC 전용, 상업화 전 교체 필수
  - 테슬라 앱 추출 에셋(공식) 후보는 재배포 불가로 **배제**
- **내관**: 모델 Y는 GLB 캐빈을 그대로 사용(유리 반투명 전환, 실내 재질 내장색 염색).
  상품·카메라 좌표는 구역별 캘리브레이션(cabinTFactory: 대시/콘솔/도어/바닥/루프 실측 레이캐스트 값)으로 매핑.
  모델 3은 캘리브레이션 전이라 절차 실내 폴백.
- **검증 루프**: Playwright 헤드리스 스크린샷으로 외관/내관/상품 장착을 직접 확인하며 튜닝
  (`vendor-test/` 로컬 three 미러 — 저장소 미포함)
- 에셋 확장자는 아티팩트 서빙 제약으로 `.glb.wasm`/`.json`/`_bin.wasm` 사용 (GLTFLoader는 내용으로 판별)
- 3DGS 실사 경로(옵션 2) 준비: `docs/3dgs/PIPELINE.md` + 뷰어 첫 화면 "실사 3DGS 베이스 열기"(.ply/.spz, Spark 렌더러) + 축/크기 보정 칩
- GLB 캐빈에서 위치 보정이 어려운 2종(스티어링 커버·킥매트)은 해당 차량에서 임시 숨김
